little endian :

                position  1    2    3    4
                1 octet : 08 - 07 - B7 - A0

                position  1      2
                2 octets: 0708 - A0B7

big endian    :

                position  1    2    3    4
                1 octet : A0 - B7 - 07 - 08

                position  1      2
                2 octets: 10B7 - 0708
